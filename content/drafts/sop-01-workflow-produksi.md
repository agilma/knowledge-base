## Konteks

SOP resmi tim, berlaku sejak **21 Oktober 2026** untuk **semua fitur baru**. Setiap fitur baru wajib lewat alur ini, dari SOW sampai launch. Tidak ada development tanpa task dan approval Project Leader (PL) lalu Project Controller (PC).

## Alur

1. **SOW.** Scope disepakati.
2. **Design Flow.** Design wajib jika flow.
3. **Approval.** Project Leader, lalu Project Controller.
4. **Development.** Kerjakan task dan test otomatis.
5. **UAT dan Simulasi.** Readiness check dengan Tim QA sampai lolos.
6. **Training dan Launch.** Buat tutorial, lalu serah terima. H+3 setelah launch, Project Leader follow-up ke client dan membuat report ke Finance.

## Wajib ada

- **SOW:** scope jelas sebelum task dibuat.
- **Task:** semua pekerjaan tercatat di Vernon Project.
- **Skenario UAT:** dibuat bersama design, sebelum approval PL lalu PC.
- **Lolos UAT:** tes dan tutorial selesai sebelum launch.

## Perhatian

Belum ada approval? **Jangan mulai development.** Lengkapi design dan skenario UAT dulu.

## Cek diri

- Task sudah ada di Vernon Project?
- Skenario UAT sudah ditulis dan PL lalu PC sudah approve?
- UAT lolos dan tutorial siap sebelum launch?
